# Networking
- Identify L2/L3 boundaries, address plans, trust zones, interfaces and failure modes.
- Treat firewall exposure and routable management endpoints as security-sensitive.
- Validate DNS, certificates, MTU, routes, NAT and IPv6 explicitly where relevant.
- Prefer reversible, measurable changes with remote-access recovery options.
