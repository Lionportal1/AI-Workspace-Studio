# Test and verification
- For changed behavior, add the smallest meaningful automated regression test when feasible.
- Establish a failing case before a bug fix where practical.
- Run targeted tests plus the appropriate project-level tests before completion.
- If tests cannot run, explain why, what was examined, and what remains unverified.
- Do not fabricate test output.
