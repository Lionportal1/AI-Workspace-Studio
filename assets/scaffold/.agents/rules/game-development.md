# Game and simulation engineering
- Preserve deterministic update order when simulation replay or multiplayer requires it.
- Separate game rules, rendering, input, asset pipelines, persistence and networking.
- Budget CPU, allocations and rendering separately; profile before optimizing.
- Test save compatibility, time-step invariants and serialization contracts.
