# Issue Triage Planning

1. Capture reproducible symptoms, affected users, severity, environment and desired behavior.
2. Separate independently shippable work from dependencies; define non-goals and acceptance criteria.
3. Rank risk, effort and impact using explicit assumptions rather than fabricated estimates.
4. Create an ordered task plan with owner-neutral checklists, verification gates and rollback notes.
5. Update plans when new evidence invalidates a dependency or assumption.
