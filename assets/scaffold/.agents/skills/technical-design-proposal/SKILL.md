# Technical Design Proposal

1. Describe the problem, existing architecture, goals, constraints and explicitly excluded scope.
2. Evaluate at least two realistic options with data flows, failure modes, migration steps and compatibility.
3. Define APIs, schemas, ownership, state transitions and clear error semantics.
4. Include rollout, privacy/security implications, performance budgets and targeted tests.
5. Highlight decisions that still require stakeholder approval before implementation.
