# Python Project Engineering

1. Inspect Python target versions, pyproject.toml, lockfiles and established lint/test tools.
2. Use clear module boundaries, type annotations and precise exceptions.
3. Prefer isolated environments, pinned dependencies and explicit CLI entrypoints.
4. Write pytest or unittest tests including I/O failures and asynchronous boundaries as needed.
5. Run formatting, type checks, tests and build packaging with recorded commands.
