# Firewall Network Segmentation

1. Diagram trust zones, interfaces, subnets, DNS authority and management paths.
2. Create a least-privilege reachability matrix with explicit inbound and outbound flows.
3. Check routing symmetry, NAT behavior, IPv6 policy, MTU, certificates and VPN peers.
4. Plan staged rule rollout with out-of-band access and a tested rollback.
5. Validate connectivity from authorized endpoints; do not expose admin planes by default.
