# Game Ai Navigation

1. Define agent goals, observations, action costs, navigation representation and update budgets.
2. Choose behavior trees, utility systems, FSMs or planners based on inspectable behavior.
3. Separate path planning, local steering, perception and action execution.
4. Test unreachable goals, dynamic obstacles, oscillation and interrupted tasks.
5. Profile worst-case AI populations and provide debugging visualizations or logs.
