# Rust Systems Engineering

1. Map crate boundaries, feature flags, MSRV and target platforms.
2. Define ownership, error types and fallible conversions at external boundaries.
3. Avoid unjustified unsafe blocks; document invariants and test concurrency assumptions.
4. Run cargo fmt, clippy and tests with appropriate features and platforms.
5. Profile allocations and performance only after correctness is established.
