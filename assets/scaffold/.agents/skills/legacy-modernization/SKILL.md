# Legacy Modernization

1. Inventory target platforms, runtime versions, dependencies, supported behaviors and unsupported APIs.
2. Select an incremental migration path that keeps the old application runnable.
3. Map breaking changes, data formats and third-party compatibility ahead of rewrites.
4. Upgrade one seam at a time with regression tests and reproducible builds.
5. Document fallback paths and remove compatibility shims only after consumers migrate.
