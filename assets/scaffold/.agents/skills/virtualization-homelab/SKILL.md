# Virtualization Homelab

1. Inventory host hardware, hypervisor, guest dependencies, shared storage and network paths.
2. Map CPU/RAM/I/O budgets, snapshot semantics, backup destinations and restore objectives.
3. Propose minimally disruptive migration and maintenance sequences with console fallback.
4. Verify permissions, disks, boot mode, firewall changes and guest service health.
5. Require approval before deleting storage, repartitioning disks or changing host networking.
