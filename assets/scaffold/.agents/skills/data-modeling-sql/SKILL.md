# Data Modeling Sql

1. Collect domain entities, invariants, expected cardinalities and access patterns.
2. Define primary/foreign keys, unique constraints, nullability and retention rules.
3. Normalize by default, then justify denormalization with measured queries.
4. Design representative transactions and migrations before enabling writes.
5. Validate referential integrity, query behavior and permissions using disposable databases.
