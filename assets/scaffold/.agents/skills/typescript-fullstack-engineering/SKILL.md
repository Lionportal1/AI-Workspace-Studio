# Typescript Fullstack Engineering

1. Inspect runtime, package manager, tsconfig strictness and generated client contracts.
2. Separate trusted domain types from untrusted HTTP, storage and UI input; validate at runtime.
3. Handle async exceptions, abort signals, SSR/client differences and accessibility.
4. Add typecheck, unit, integration and representative E2E tests.
5. Check bundle size, API backwards compatibility and deployment assumptions.
