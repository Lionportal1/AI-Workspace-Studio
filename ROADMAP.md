# Project Roadmap

## Before the first stable release

- [ ] Select and approve an open-source license, then add LICENSE.
- [ ] Merge bootstrap PR and verify the Windows/macOS/Linux CI matrix.
- [ ] Configure GitHub rulesets for main/develop and the protected production-release environment.
- [ ] Validate standalone installers on actual target machines.
- [ ] Publish v3.1.0 through the manual release workflow, after approval.

## Later releases

- [ ] Pin external community repositories and implement integrity policy.
- [ ] Improve transactional writes, backups and rollback behavior.
- [ ] Review MCP package versions and vendor configuration formats.
- [ ] Add package-manager distribution after security and maintenance review.
- [ ] Consider a richer terminal UI, update management and signed release artifacts.
